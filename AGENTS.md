# C++ Codebase Analyzer

## READ FIRST — before any work in this repo

Read **`PROJECT_CONTEXT.md`** (repo root) in full before answering questions or making changes. It is
the index of the project context — current state, how to read the rest, and which file holds what —
and is kept short so it reads in one go.

The detail is in **`project-context/`**: topic files (architecture, each pipeline phase, CLI and config,
incremental generation, API and frontend, risks and decisions) and the dated history of every change,
each small enough to read whole. Before you change an area, read its topic file. The coding rules for
each role are in `.claude/skills/<role>/SKILL.md` and apply to any assistant.

Do not rely on memory or assumptions — read the files. They are kept up to date after every meaningful change.
